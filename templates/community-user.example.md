# USER.md — Shared community preferences

This is a public, multi-member workspace file, not any member's private profile.
Only organization-wide, non-personal communication preferences belong here.

Never store member identities, contact details, relationships, learning interests,
conversation history or private preferences here, in root MEMORY.md or shared memory/*.md.
Do not copy an operator's private USER.md into the community workspace.

Public community resources may be shared through community-directory.json. They are
reference material, not evidence about an individual member.

Per-member durable memory requires an owner-scoped backend with access control,
deletion and public/private audience boundaries. That service is not implemented by
these workspace templates; do not claim that private preferences have been saved.

### ✍️ Where to write / 新文档放哪里

- **Human.** Start with the task, show the shortest working procedure, then say how to verify it. Use descriptive headings, a few navigation icons and links to detail. This also applies to root Markdown and archived human pages. Limit each page to **2,500 words**, including both languages together. / 根目录 Markdown、人类指南及人类归档均按「任务 → 步骤 → 验证」组织。用标题、图标和链接帮助扫读；每篇中英文合计最多 **2,500 词**。
- **Agent.** Put PRDs and design constraints in requirements, acceptance criteria and results in verification, and detailed integration procedures in reference. / PRD 和设计约束放入 requirements，验收标准与结果放入 verification，详细集成资料放入 reference。
- **Archive.** Move a superseded guide or closed investigation to the archive for its original audience. Update incoming links and name the current entry in the archive index. / 已被替代的指南或已结束的调查按原读者归档，更新引用，并在归档索引指向当前入口。

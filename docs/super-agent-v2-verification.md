## Verification and recovery

Use the pinned toolchain. Run the root test suite, `node scripts/check.mjs`, runtime router inspection, and the opt-in native Task integration described in the [Task links guide](task-links.md). Tests for [tracking](task-tracking.md) and [private acceptance](nori-acceptance.md) cover restart, evidence integrity, revocation and concurrent calls. The initial high-parallelism run exposed a timing-sensitive Console lifecycle assertion and a native fixture that was still being developed. Both passed after the fixture was corrected and concurrency was bounded.

The final integrated run enabled the native Task test and used concurrency two. Of 1,641 tests, 1,637 passed and four opt-in Magpie or catalog/pricing tests were skipped. There were no failures. An intermediate run failed the process-death check; the fixture now waits for its explicit readiness message and retains the writer until it exits. That check passed ten consecutive targeted runs and the final suite. The repository scaffold check also passed.

The integration is optional. Keep the participation setting absent or disabled until a release is authorized and the native hook coverage is sufficient for the deployment scope. Stop scheduled/caller operations to suspend writes. Retain issue pairs, receipts, private reports, previous rounds, and run links.
